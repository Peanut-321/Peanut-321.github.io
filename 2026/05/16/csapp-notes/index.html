学习路线

当前目标偏嵌入式，不按原书平均推进。优先顺序：

阶段安排

第 1 阶段：信息表示与位运算

对应内容：

  • 第 2 章：信息的表示和处理
  • Data Lab 的前半部分

重点：

  • 十六进制、二进制、字节、字长
  • 补码、有符号数、无符号数
  • 溢出、截断、符号扩展
  • 位运算：&、|、^、~、<<、>>
  • 大端序和小端序
  • 浮点数基本结构

嵌入式价值：

  • 配置寄存器
  • 写 bit mask
  • 解析通信协议
  • 理解传感器原始数据
  • 避免整数溢出和类型转换 bug

第 2 阶段：机器级表示

对应内容：

  • 第 3 章：程序的机器级表示
  • Bomb Lab
  • Attack Lab

重点：

  • x86-64 汇编的基本阅读能力
  • 函数传参、返回值、栈帧
  • 条件码、跳转、循环、递归
  • 数组、指针、结构体、内存布局
  • GDB 调试和反汇编

嵌入式价值：

  • 看懂反汇编
  • 调试 crash
  • 理解栈溢出和内存破坏
  • 为后续看 ARM 汇编、启动代码、中断现场打基础

第 3 阶段：链接

对应内容：

  • 第 7 章：链接

重点：

  • .c、.s、.o、可执行文件
  • 符号表、重定位
  • 静态库、动态库
  • undefined reference、multiple definition

嵌入式价值：

  • 理解 Makefile / CMake
  • 理解交叉编译
  • 看懂链接脚本和启动文件
  • 处理全局变量、静态变量、段布局问题

第 4 阶段：存储器层次结构

对应内容：

  • 第 6 章：存储器层次结构
  • Cache Lab

重点：

  • SRAM、DRAM、Flash
  • 局部性
  • cache line、set、tag
  • cache miss
  • cache 友好的代码

嵌入式价值：

  • 理解 memory map
  • 理解 cache 和 DMA 的关系
  • 优化数组、矩阵、图像处理代码
  • 为 memory barrier / cache coherence 打基础

第 5 阶段：虚拟内存与动态分配

对应内容：

  • 第 9 章：虚拟内存
  • Malloc Lab

重点：

  • 虚拟地址、物理地址、页表
  • 堆、栈、全局区
  • malloc / free
  • 内部碎片、外部碎片
  • 隐式空闲链表、显式空闲链表

嵌入式价值：

  • 嵌入式 Linux：理解进程地址空间和 mmap
  • RTOS / 裸机：理解堆管理、碎片、内存池
  • 写长期运行程序时避免内存泄漏

第 6 阶段：异常控制流

对应内容：

  • 第 8 章：异常控制流
  • Shell Lab 的概念部分

重点：

  • 异常、中断、陷阱、故障
  • 进程、上下文切换
  • fork、execve、waitpid
  • 信号

嵌入式价值：

  • 理解嵌入式 Linux 应用和服务进程
  • 理解信号处理、子进程回收
  • 和裸机中断/异常建立类比

复盘问题

每学完一小节，用这些问题检查：

  • 这个概念在 C 代码里表现成什么？
  • 如果出 bug，会出现什么现象？
  • 我能不能画出内存布局？
  • 我能不能用一个最小例子验证它？
  • 它和嵌入式里的寄存器、内存、编译、调试有什么关系？
