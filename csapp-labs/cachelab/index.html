3. 嵌入式关联

Cache Lab 对嵌入式很有价值：

  • 理解数组访问顺序为什么影响性能
  • 理解 cache line
  • 理解 DMA 和 cache 不一致问题的背景
  • 为图像处理、信号处理、矩阵计算优化打基础

4. 复盘重点

  • 一个地址如何拆成 tag / set / offset？
  • 为什么连续访问数组更快？
  • 为什么矩阵转置容易 cache miss？
  • 什么是 LRU？
  • 分块为什么能减少 miss？
