9. 复盘重点

Bomb Lab 真正要训练的是：

  • 看到 call 前几行，能判断参数是什么
  • 看到 cmp/test + jump，能还原 if
  • 看到循环跳回去，能还原 for / while
  • 看到 jmp *table(,%rax,8)，能想到 switch
  • 看到 (%rsp,%rax,4)，能想到数组
  • 看到 0x8(%node)，能想到结构体字段或链表指针
